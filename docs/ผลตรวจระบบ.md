## จุดที่ปรับ

- รวมตัวช่วยทดสอบไว้ใน tests/support เพื่อไม่ต้องอ้างโฟลเดอร์สำรองภายนอกโครงการ
- แก้ตัวช่วย AppTest ให้ชี้ app.py จากตำแหน่งโครงการโดยตรง
- เพิ่ม tools/test_system.py สำหรับรันชุดทดสอบและกำหนดพื้นที่ชั่วคราวภายในโครงการ
- จัด README เป็นภาพรวม คู่มือผู้ใช้ บทบาท ขั้นตอนยืมคืน วิธีติดตั้ง และการทดสอบ พร้อมลิงก์คู่มือ Word ฉบับหลัก
- ยกเว้นฐานข้อมูล เอกสารอัปโหลด และสำเนาสำรองจาก Git

## วิธีตรวจซ้ำ

```powershell
.\.venv\Scripts\python.exe tools/test_system.py
.\.venv\Scripts\python.exe check_sqlite.py
```
